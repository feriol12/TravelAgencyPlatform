# HANDOFF.md

## Purpose

Use this file only for unfinished/transitional work passed from one agent to another.

Git + documentation + this file are the transfer mechanism.
Do not depend on previous AI chat history.

## Status

Use one:

- READY_TO_CONTINUE
- BLOCKED
- NEEDS_HUMAN_DECISION
- UNSTABLE

## Receiver checks

Before editing:
- verify repository/worktree;
- verify branch;
- verify HEAD;
- verify working-tree state;
- read active card;
- read relevant docs;
- confirm no unresolved human decision blocks progress.
